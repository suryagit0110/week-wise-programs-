## Detailed Weekly Summary

### Week 1: Basic HTML Text Formatting Tags
- Demonstrates HTML document structure and fundamental text styling tags:
  - Headings (`<h1>` to `<h6>`)
  - Text formatting: `<b>`, `<strong>`, `<i>`, `<em>`, `<u>`, `<del>`, `<mark>`, `<small>`, `<big>`, `<sub>`, `<sup>`
  - Preformatted text: `<pre>`
  - Horizontal rules: `<hr>`

### Week 2: Multimedia & Navigation
- Demonstrates multimedia embedding and navigation:
  - Image embedding (`<img>`)
  - Video player controls (`<video>`, `<source>`)
  - Internal anchor hyperlinks (`<a href="#id">`)
  - Unordered lists (`<ul>`, `<li>`)
  - Contact links (`mailto:` and `tel:`)

### Week 3: HTML Tables & Student Marks Sheet
- Demonstrates advanced table layout and semantics:
  - `<table>`, `<caption>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`
  - Complex multi-level headers using `rowspan` and `colspan`
  - Data representation for student marks with registration number `261FD01035`

### Week 4: HTML Frames and Hyperlink Navigation
- Demonstrates multi-page framed navigation layout:
  - Master frameset with 2-column division (`<frameset cols="25%,75%">`)
  - Interactive sidebar menu targeting the content viewport (`target="content"`)
  - Modular pages: Home, Student Profile, Courses, and Contact Details

### Week 5: HTML Forms & User Input
- Demonstrates complete HTML5 form components and validation:
  - **Student Registration Form (`index.html`)**: Text input, Email, Password, Radio buttons, Date picker, Select dropdown, Checkboxes, Textarea, Submit & Reset buttons.
  - **Login Form (`login.html`)**: User credentials verification layout.
  - **Feedback Form (`feedback.html`)**: Rating options, feature checklist, and feedback comments box.
